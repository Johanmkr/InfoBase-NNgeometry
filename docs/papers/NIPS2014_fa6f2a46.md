# On the Number of Linear Regions of Deep Neural Networks

**Montúfar, Pascanu, Cho, Bengio (2014)**, *Advances in Neural Information Processing Systems 27*.

!!! abstract "TL;DR"
    A piecewise linear network partitions its input space into *linear regions*, and this count is used as a measure of how complex a function the architecture can represent. The paper argues that each hidden layer can fold its input space so that the computation of later layers is *identified* — replicated — across many input neighborhoods, making the number of regions grow exponentially with depth and only polynomially with width. It proves a lower bound of $\Omega((n/n_0)^{(L-1)n_0}n^{n_0})$ regions for a width-$n$ rectifier network of depth $L$, improving on the bound of [@pascanuNumberResponseRegions2013], and analogous exponential-in-depth bounds for rank-$k$ maxout networks.

## Problem and motivation

The universal approximation theorems (Hornik et al. 1989; Cybenko 1989, outside the collection) only guarantee that a single wide layer can approximate, and do not explain the empirical preference for deep networks (§1, p. 1). [@pascanuNumberResponseRegions2013] had shown that in the limit of many layers a deep rectifier network separates its input space into exponentially more *response regions* than a shallow network with the same number of units; the present paper asks how much of this advantage survives at moderate depth, and generalises the analysis from rectifiers to any piecewise linear activation, with maxout as a second worked example.

The quantity studied is the number of *linear regions* of the function computed by the network: for $F:\R^{n_0}\to\R^{m}$ piecewise linear, a linear region is a maximal connected subset of the input space on which $F$ is linear; for the functions considered every such region has full dimension $n_0$ (§2.1, p. 3). The formal setting is a feedforward network $F = f_{\mathrm{out}}\circ g_L\circ f_L\circ\cdots\circ g_1\circ f_1$ with preactivations $f_l(x_{l-1}) = W_l x_{l-1}+b_l$ and piecewise linear activations $g_l$, either rectifiers $g_i(f_i)=\max\{0,f_i\}$ or rank-$k$ maxout units $g_i(f_i)=\max\{f_{i,1},\dots,f_{i,k}\}$ (§2.1, p. 3). A network *structure* is fixed by the input dimension $n_0$, the number of layers $L$ and the widths $n_l$.

For a shallow rectifier layer the hyperplanes $H_i=\{x: W_{i,:}x+b_i=0\}$ where each unit switches form a hyperplane arrangement, and the classical result of [@zaslavskyFacingArrangementsFacecount1975] gives at most $\sum_{j=0}^{n_0}\binom{n_1}{j}$ regions, attained exactly when the hyperplanes are in general position; this bounds the maximal number of linear regions of a shallow rectifier network (§2.2, p. 3).

## Method

The engine of the paper is the observation that each layer can map several disjoint regions of its input to the *same* output, so that whatever the following layers compute is replicated in all of them. This is formalised as identification.

*Definition 1* (§2.3, p. 3): a map $F$ *identifies* two neighborhoods $S$ and $T$ if $F(S)=F(T)$. The canonical example is the absolute value $g:\R^2\to\R^2$, $(x_1,x_2)\mapsto[\lvert x_1\rvert,\lvert x_2\rvert]^\top$, which identifies the four quadrants (Example 2, p. 3).

The construction then proceeds by choosing the parameters of the first $L-1$ layers to fold as many input neighborhoods as possible onto the same activations, and letting the last hidden layer partition that single folded space into many regions. Writing $P^l_R$ for the collection of subsets of layer $l-1$ activations that layer $l$ maps onto a given neighborhood $R$, the number of input neighborhoods mapped onto $R$ satisfies the recursion of Eq. 2, and Lemma 3 turns it into a lower bound on the number of regions (§2.3, p. 4).

This picture is described as *space folding* (§2.4, pp. 4–5): a folding map collapses a region onto its image; composing the foldings of successive layers folds the input space recursively, and any function computed on the final folded space applies to every collapsed subset. The foldings need not be along coordinate axes and need not preserve lengths — their shapes follow the weights, biases and activations (§2.4, p. 5, Fig. 3). For the deep rectifier result the construction folds each input coordinate independently by $p=\lfloor n/n_0\rfloor$ units of alternating sign (§3.1, p. 6), producing $p^{n_0}$ identified hypercubes whose image is a single hypercube, on which the last layer acts.

## Key equations and definitions

The network function and the counting recursion (§2.1, p. 3; §2.3, p. 4) (Eq. 1, p. 3; Eq. 2, p. 4):

$$
F(x;\theta) = f_{\mathrm{out}}\circ g_L\circ f_L\circ\cdots\circ g_1\circ f_1(x)
$$

$$
N^l_R = \sum_{R'\in P^l_R} N^{l-1}_{R'}, \qquad N^0_R = 1 \quad\text{for each region } R\subseteq\R^{n_0}
$$

Lemma 3 (§2.3, p. 4): the maximal number of linear regions of an $L$-layer piecewise linear network is at least

$$
N = \sum_{R\in P^L} N^{L-1}_R,
$$

where $P^L$ is a set of neighborhoods in distinct linear regions of the last hidden layer. No proof is given in the main text.

The elementary folding unit of §3.1 (p. 6), a sum of $p$ rectifiers with alternating signs (Eq. 3, p. 6):

$$
\tilde h_j(x) = [1,-1,1,\dots,(-1)^{p-1}]\,[h_1(x),h_2(x),h_3(x),\dots,h_p(x)]^\top
$$

with $h_r(x)=\max\{0,2wx-(r-1)\}$ and $w$ selecting the $j$-th input coordinate; $\tilde h_j$ has $p$ linear regions and identifies the input strips $(0,1),(1,2),\dots,(p-1,p)$.

The main lower bound, Theorem 5 (p. 7) (Thm. 5, p. 7):

$$
\prod_{i=1}^{L-1}\left\lfloor\frac{n_i}{n_0}\right\rfloor^{n_0}\left(\sum_{j=0}^{n_0}\binom{n_L}{j}\right)
$$

for a network with $n_0$ inputs and $L$ hidden layers with $n_i\ge n_0$ rectifiers per layer. Its asymptotic form, Corollary 6 (p. 7): a rectifier network with $L$ hidden layers of width $n\ge n_0$ can compute functions with

$$
\Omega\!\left(\left(\frac{n}{n_0}\right)^{(L-1)n_0} n^{n_0}\right)
$$

linear regions, against the earlier $\Omega((n/n_0)^{L-1}n^{n_0})$ of [@pascanuNumberResponseRegions2013] (§3.2, p. 7). The proof of Thm. 5 is in the Supplementary Material.

For maxout, the shallow bound, Proposition 8 (p. 8): a single-layer maxout network with $n$ inputs and $m$ outputs of rank $k$ has a maximal number of regions lower bounded by $k^{\min\{n,m\}}$ and upper bounded by $\min\{\sum_{j=0}^{n}\binom{k^2 m}{j},\,k^{m}\}$. The deep bound, Theorem 9 (p. 8): a maxout network with $L$ layers of width $n_0$ and rank $k$ can compute functions with at least

$$
k^{L-1}k^{n_0}
$$

linear regions. A rank-$2$ maxout layer is simulated by a rectifier layer of twice the width, giving $2^{n_0(L-1)}$ identified input regions and $2^{n_0 L}$ regions computed (§4, p. 8).

## Main results

- **Upper bound (Prop. 4, p. 6).** Any rectifier network with $N$ hidden units computes at most $2^N$ linear regions, since each region corresponds to an activation pattern.
- **Deep rectifier lower bound (Thm. 5, Cor. 6, p. 7).** The maximal number of linear regions grows exponentially in $L$ and polynomially in $n$, faster than the shallow model with $nL$ hidden units, whose count behaves as $O(L^{n_0}n^{n_0})$ (§3.2, p. 7, citing Pascanu et al. 2013, Prop. 10). The improvement over the previous $\Omega((n/n_0)^{L-1}n^{n_0})$ shows a depth advantage already at small $L$ and $n$.
- **Shallow maxout (Prop. 8, p. 8).** Lower bound $k^{\min\{n,m\}}$, upper bound $\min\{\sum_{j=0}^{n}\binom{k^2 m}{j},k^{m}\}$ on the regions of one maxout layer; the number of regions of a single maxout unit equals its rank $k$ (§4, p. 7).
- **Deep maxout (Thm. 9, p. 8).** $\ge k^{L-1}k^{n_0}$ regions, again exponential in depth; the constructions for rectifier and maxout networks are different, and the rectifier functions of §3 are not computable by maxout networks except in the rank-$2$ case (§4, p. 8).
- **Robustness of the counts (§2.5, p. 5).** Because linear regions have finite volume and the parameter-to-function map is continuous, any parameter choice attaining a given number of regions is surrounded by an $\epsilon$-ball of parameters attaining at least that many; the maximal count is therefore not a measure-zero accident (shallow rectifier networks generically attain their maximum).

## Limitations stated by the authors

The bounds are lower bounds obtained by explicit constructions and are stated only for suitable choices of the weights; the authors note they are not conclusive about which of rectifier and maxout is more powerful, which they call an interesting question (§5, p. 8). The works are worst-case: the paper does not say how many linear regions typical trained networks have, and it leaves open whether many parameter-space regions correspond to functions with a given number of regions (§2.5, p. 5; §5, p. 5).

## Critical assessment

The paper is a landmark of the "counting linear regions" line and its depth-versus-width message has held up, but the fine print matters. All the quantitative results are *maximal* counts, i.e. existential: Thm. 5 and Thm. 9 exhibit parameter choices, and the $\epsilon$-ball argument of §2.5 only says the maximal count is not a knife-edge, not that training finds it. Later work in this collection ([@haninComplexityLinearRegions2019], [@haninDeepReLUNetworks2019]) showed that typical random and trained networks have far fewer regions than the maximum, which is a genuine qualifier the present paper does not address. The empirical support is very thin: Fig. 1 is a single binary-classification illustration (shallow 20 units versus two layers of 10 units) whose details are deferred to the Supplementary Material, which is not part of this file, and §2.6 only demonstrates a visualisation technique for hidden-unit foldings; no dataset is named in the main text and no code or data are released. Two constructions are asserted with proofs placed in the Supplementary Material (Lemma 3 and Thm. 9, and the proof of Thm. 5), so reproducibility of the arguments requires material this file does not contain. The maxout upper bound $\min\{\sum_{j=0}^{n}\binom{k^2 m}{j},k^{m}\}$ (Prop. 8) uses the crude bound $k^2m$ on the number of boundary hyperplanes (there are generically $m\binom{k}{2}$), so it is not tight; the paper does not tighten it. Finally the comparison with [@pascanuNumberResponseRegions2013] is presented as an improvement of the exponent from $L-1$ to $(L-1)n_0$, which is a real gain only for $n_0>1$ (trivially for $n_0=1$ the two coincide).

## Connections within the collection

The paper is the direct continuation of [@pascanuNumberResponseRegions2013], which introduced response regions for piecewise linear networks and the shallow/deep comparison; here that framework is generalised to arbitrary piecewise linear activations and the rectifier lower bound is sharpened, and the two summaries should be read together. It relies on the hyperplane-arrangement region count of [@zaslavskyFacingArrangementsFacecount1975] for the shallow case (§2.2, p. 3), the third collection paper directly at the root of this line.

The counting thread it starts is continued by [@serraBoundingCountingLinear2018] (tighter width/depth bounds and an algorithm to count regions of a fixed network), [@raghuExpressivePowerDeep2017] (trajectory-based complexity and the first upper-bound refinements), and [@goujonNumberRegionsPiecewise2023], which recovers the present rectifier bound as a special case of its general CPWL analysis (Eq. 18) and extends it to maxout and other activations. The maxout part connects to [@zhangTropicalGeometryDeep], which reproves these counting bounds via tropical geometry, and to [@alfarraDecisionBoundariesNeural2023], which builds decision-boundary results on the same tropical view. The worst-case bias of these counts is precisely the target of [@haninComplexityLinearRegions2019] and [@haninDeepReLUNetworks2019], which study the average-case number of regions and activation patterns as a counterweight. The spline/partition view in which the objects counted here are the pieces of an affine spline is developed by [@balestrieroSplineTheoryDeep2018] and made computational by [@humayunSplineCamExactVisualization2024], while [@masdenAlgorithmicDeterminationCombinatorial2022] and [@berzinsPolyhedralComplexExtraction2023] compute the underlying polyhedral complex rather than just bounding the top-dimensional region count. [@carlssonPREIMAGERECTIFIERNETWORK2017] inverts the same layer-wise hyperplane picture.
